The Demos Network primarily consists of two main parts, divided into the repositories `sdks` and `node`.

The **`sdks`** repository includes types, methods, and interfaces used in both frontend and backend. It contains most of what you need to interact with the Demos Network from a dApp, plus the building blocks for a custom client. See the [SDK Getting Started](/sdk/getting-started) guide for an introduction, or the [WebSDK overview](/sdk/websdk/overview) for the main client surface.

The **`node`** repository contains the official implementation of Demos Network specifications for a backend client (commonly known as a node). Nodes form the core of the network and can act either as validators or as synced read-only nodes. For an in-depth tour of node-side mechanisms, start with [Internal Mechanisms](/backend/internal-mechanisms/overview), [Consensus Mechanism](/backend/consensus-mechanism/overview), and the [Global Change Registry](/backend/global-change-registry/overview).
